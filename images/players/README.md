# Player photos

Drop photos here. The site looks for, in order:

1. `images/players/<player-id>/<season>.jpg`  (e.g. `lebron-james/2012-13.jpg`, a photo for that exact year)
2. `images/players/<player-id>.jpg`  (one photo used for every year)
3. Otherwise it shows the player's initials in a circle.

Only add photos you have the right to use (your own, or licensed/Creative Commons with credit in the README).
Square crops (about 400x400) look best.
